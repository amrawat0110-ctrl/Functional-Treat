# 📘 README.md - Functional Treat: Data Analyzer and Transformer Program

---

# 📌 Project Description

**Functional Treat: Data Analyzer and Transformer Program** is a menu-driven Python application that allows users to input numerical data and perform various data analysis and transformation operations. The project demonstrates important Python concepts such as recursion, lambda functions, built-in functions, sorting, functions with `*args` and `**kwargs`, returning multiple values, and global variables. :contentReference[oaicite:0]{index=0}

---

# ✨ Features

- Input numerical dataset
- Display Data Summary
- Calculate Factorial using Recursion
- Filter Data using Lambda Function
- Sort Data (Ascending & Descending)
- Display Dataset Statistics
- Menu Driven Interface
- Exit Program

---

### Step 2

```

```

### Step 4

```bash
python "python project 4.py"
```

# ▶️ Usage

Run the program and select an option from the menu.

```
1. Input Data
2. Display Data Summary
3. Calculate Factorial
4. Filter Data
5. Sort Data
6. Display Dataset Statistics
7. Exit
```

Follow the instructions displayed on the screen.
